# Demo laptop runbook: David's parts (D1, D2, D3)

Run everything from the repo root, with the venv active and `.env` loaded:
```
source .venv/bin/activate
set -a; source .env; set +a
```

## `.env` values my parts read
| Var | Needed for | Note |
| --- | --- | --- |
| `GROQ_API_KEY` | parent sentences → rules, pack from a sentence | without it, compile returns 502; packs fall back to cache |
| `DIRECTIVE_PIN` | PIN card | empty = every PIN refused (fail closed) |
| `COMPILER_SHARED_SECRET` | compiler → core `POST /directives` | must be the **same value** the core runs with, else 403 |
| `CORE_API_URL` | compiler, conformance, `demo_pack` | `http://localhost:8001` |
| `LANGSMITH_API_KEY` | only for `--trace` runs | keep `LANGSMITH_TRACING=false` in `.env` |

## 1. Parent rule (D1): runs inside the UI
`ui/run_demo.sh` starts the compiler on :8002. Check it once:
```
curl -s -X POST localhost:8002/directives/compile -H 'content-type: application/json' \
  -d '{"pack_id":"pack_video_demo","scope_id":"child_7","text":"no spooky videos for a week"}'
```
Expect a `suppress` on `topic: spooky` with an `expires_at` 7 days out.

## 2. Pack from a sentence (D2): terminal beat, about 20 s
```
python -m compiler.demo_pack "A team memory assistant that forgets notes after 30 days"
python -m compiler.demo_pack --cached "A team memory assistant that forgets notes after 30 days"   # if Groq is slow or rate-limited
```
Shows: pack generated by the LLM (or from cache), registered, conformance with all 5 checks, then active. Core refuses anything below 5/5.

## 3. Proof (D3): run once before recording, show the output or the evidence files
```
python -m eval.retract_one --core http://localhost:8001 --trace   # real planner: expect PASS, dec_02/03 recalled, dec_08 kept
python -m eval.memory_eval --trace                                # with memory 98% personalised vs 0% without, gate 100%
python -m compiler.conformance --pack data/pack_video.json        # same 5 checks from outside the core
```
Offline fallback, which needs no core: `python -m eval.retract_one`. Evidence lands in `eval/evidence/`, and traced runs land in LangSmith project `memory-governance-eval`.

## If something fails
- 403 `forbidden` on a parent rule: `COMPILER_SHARED_SECRET` differs between the core and the compiler.
- 422 `not_confirmed`: wrong PIN, or 3 misses locked that child for 5 minutes (restart the compiler to clear it).
- 502 `internal` on compile: Groq key missing or rate-limited. Wait 30 s and pause between sentences.
